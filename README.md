# VOY PRO Website

Staging deployment repository for the VOY PRO website.

Current staged release: **v1.32.1**.

v1.32.1 is a visual/navigation polish release on top of v1.32:
- reduces destructive image cropping so the EZRaider chassis and wheels remain visible more often;
- moves hero photography to a 4:3 frame with a lower focal point;
- removes ultra-wide gallery crops and uses more natural 3:2 framing;
- keeps Portugal explicitly visible as a destination link in the compact 801–1180px Budapest header;
- preserves Portugal in the compact/mobile menu;
- retains the v1.32 locale-safe shared header/footer, booking-intent deep links and internal-copy QA.

The existing reviewed v1.31 staging artifact remains the immutable base. Build-time overrides apply v1.32 and v1.32.1 on top of it.

Production booking is not enabled by this staging repository.
