# VOY PRO Website

Staging deployment repository for the VOY PRO website.

Current staged release: **v1.32.4**.

v1.32.4 polishes the top-left brand/location lockup:
- VOY PRO and the active location now read as one branded unit rather than a logo plus a separate pill button;
- the location selector uses a clean typographic treatment with a subtle divider and dropdown arrow;
- VOY PRO remains slightly more dominant while Budapest / Portugal · Marvão is visually matched in scale and rhythm;
- responsive sizes are tuned for desktop, tablet and mobile;
- the full-photo presentation and multilingual location selector from v1.32.2–v1.32.3 remain active.

Production booking is not enabled by this staging repository.
